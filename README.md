📊 Tableau de Bord – Satisfaction des Employés (Power BI)
🚀 Présentation du projet

Ce projet consiste en la réalisation d’un tableau de bord interactif sous Power BI permettant d’analyser la satisfaction des employés à partir de plusieurs facteurs RH.

🎯 Objectifs :

Comprendre les facteurs influençant la satisfaction des employés

Identifier des tendances et des comportements

Aider à la prise de décision en ressources humaines

🗂️ Description de la base de données

📁 Fichier utilisé : Employee_Satisfaction_Index.csv

📌 Colonnes :
emp_id → Identifiant unique de l’employé

age → Âge

Dept → Département

location → Localisation

education → Niveau d’éducation

recruitment_type → Type de recrutement

job_level → Niveau de poste

rating → Évaluation de performance

onsite → Travail sur site ou à distance

awards → Nombre de récompenses

certifications → Certifications obtenues

salary → Salaire

satisfied → Niveau de satisfaction (variable cible 🎯)
